# Demo Script (about 4 minutes)

Use this order for the presentation or the demo video.

| Time | Show                                                                       | Say                                                                      |
| ---- | -------------------------------------------------------------------------- | ------------------------------------------------------------------------ |
| 0:00 | Home page, switch EN ⇄ BM                                                  | Problem: logic gates are abstract; Circuit Break makes them hands-on.    |
| 0:20 | Learn Gates: flip A and B on the AND card                                  | Students can explore each gate's truth table before playing.             |
| 0:40 | World Map: 5 worlds, 30 levels, locked levels                              | Levels go from NOT up to a half adder.                                   |
| 1:00 | Level 1 tutorial → place NOT → Test circuit → 3 stars + confetti           | Objective 1: evaluate a gate's output.                                   |
| 1:30 | Double Lock: place OR → Test → results table, red ✗ → click a row          | The game tests every input combination, not just one.                    |
| 2:00 | Hint → Show hint → Bit's AI hints 1, 2, 3                                  | Bit sees the student's actual circuit and guides without giving answers. |
| 2:40 | Broken Alarm (World 4): remove wrong gates, place the right ones           | Objective 2: build and repair circuits.                                  |
| 3:10 | Settings: colour-blind mode → wires show 0 / 1; keyboard play              | Accessible for every student.                                            |
| 3:30 | Phone: installed app, airplane mode on, still playable                     | Works in school labs with weak Wi-Fi.                                    |
| 3:45 | `npm run test:e2e:ui`: the robot solving all 30 levels; green CI on GitHub | 217 automated tests check every change.                                  |
