# Logic Gate Quiz · Kuiz Get Logik

Use the **same quiz before and after** playing. Each question is worth 1 mark (total 8).
Gunakan **kuiz yang sama sebelum dan selepas** bermain. Setiap soalan bernilai 1 markah (jumlah 8).

**1.** An AND gate has inputs A = 1 and B = 0. What is the output?
Get AND mempunyai input A = 1 dan B = 0. Apakah outputnya?

(a) 0 (b) 1

**2.** Which gate gives output 1 when **at least one** input is 1?
Get manakah yang memberi output 1 apabila **sekurang-kurangnya satu** input ialah 1?

(a) AND (b) OR (c) NOT (d) NOR

**3.** A NOT gate has input 0. What is the output?
Get NOT mempunyai input 0. Apakah outputnya?

(a) 0 (b) 1

**4.** Which gate gives output 1 **only** when both inputs are 0?
Get manakah yang memberi output 1 **hanya** apabila kedua-dua input ialah 0?

(a) NAND (b) XOR (c) NOR (d) AND

**5.** For a NAND gate, which input gives output **0**?
Bagi get NAND, input manakah yang memberi output **0**?

(a) A = 0, B = 0 (b) A = 0, B = 1 (c) A = 1, B = 0 (d) A = 1, B = 1

**6.** Which gate gives output 1 when the two inputs are **different**?
Get manakah yang memberi output 1 apabila dua input itu **berbeza**?

(a) OR (b) XOR (c) AND (d) NAND

**7.** Y = (NOT A) OR B. If A = 1 and B = 0, what is Y?
Y = (NOT A) OR B. Jika A = 1 dan B = 0, apakah nilai Y?

(a) 0 (b) 1

**8.** A and B go into an AND gate. Its output and C go into an OR gate, which gives Y.
If A = 0, B = 1 and C = 1, what is Y?
A dan B masuk ke get AND. Output get itu dan C masuk ke get OR, yang memberi Y.
Jika A = 0, B = 1 dan C = 1, apakah nilai Y?

(a) 0 (b) 1

## Answer key · Skema jawapan (for testers only)

| Q   | Answer           | Why                                           |
| --- | ---------------- | --------------------------------------------- |
| 1   | (a) 0            | AND needs every input to be 1.                |
| 2   | (b) OR           | OR needs at least one 1.                      |
| 3   | (b) 1            | NOT flips the signal.                         |
| 4   | (c) NOR          | NOR = NOT OR: 1 only when all inputs are 0.   |
| 5   | (d) A = 1, B = 1 | NAND = NOT AND: 0 only when all inputs are 1. |
| 6   | (b) XOR          | XOR is 1 when the inputs are different.       |
| 7   | (a) 0            | NOT 1 = 0, and 0 OR 0 = 0.                    |
| 8   | (b) 1            | 0 AND 1 = 0, and 0 OR 1 = 1.                  |

Questions 1–6 test **Objective 1** (evaluate gate outputs). Questions 7–8 test **Objective 2** (combined circuits).
